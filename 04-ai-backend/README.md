# 04 · AI 服务后端系统

把前面做好的 AI 能力做成一个可以运行和维护的服务。

## 要验证什么

能否把 AI 能力做成服务。

## 需要留下的成果

- [ ] API 设计（请求/响应、错误结构、流式接口）
- [ ] 数据持久化（会话、消息、任务）
- [ ] 后台任务（异步生成、长任务、重试）
- [ ] Docker Compose 一键起服务
- [ ] 测试与基础 CI

## 验收

- 别人按说明能自己跑起来
- 能解释服务的输入、输出、成功标准和失败处理
- 关键路径有测试保护

## 交付物

README、运行说明、Docker Compose、测试、CI 配置。
