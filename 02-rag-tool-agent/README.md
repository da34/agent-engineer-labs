# 02 · RAG + Tool Calling Agent

把资料变成可检索、可引用的证据，再让 Agent 用工具完成问答。

## 要验证什么

能否用资料和工具完成问答。

## 需要留下的成果

- [ ] 文档处理：加载、切分（chunking）、元数据
- [ ] 检索与向量化，来源引用可追溯
- [ ] 至少 2 个工具（例如查询、计算、外部 API）
- [ ] 串联 / 路由 / 并行 / 动态分工等模式，说清各自适合什么任务
- [ ] 不少于 20 条测试问题与失败分析

## 验收

- 回答能给出可核对的来源引用
- 能解释一次「检索 → 工具 → 生成」的完整链路
- 对失败案例有分类和归因，而不是只记录「答错了」

## 交付物

README、运行说明、测试问题集、失败分析。
